# MadStrap

Simple Atari Mad-Pascal common project bootstrap.

Designed to speed up project development startup, providing set useful optional features:

- constants in separate file
- type definitions in separate file
- external resource loading (RMT, ASM, strings)
- external library path definition
- custom charset 
- custom display list
- custom vertical blank interrupt
- custom display list interrupt

You just download, and uncomment all features you might need in your project.
